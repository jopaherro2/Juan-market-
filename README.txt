DESCRIPCIÓN DEL PROYECTO:
Aplicación de consola desarrollada en C# (.NET) que implementa dos estructuras de datos avanzadas desde cero:
1. Árbol AVL Auto-balanceado: Para la administración y control de inventario de productos con códigos únicos y rotaciones automáticas.
2. Cola de Prioridad mediante Heap Binario: Para la gestión de turnos en cajas con niveles VIP, Adulto Mayor y Regular, respetando el orden de llegada (FIFO).

INSTRUCCIONES DE COMPILACIÓN Y EJECUCIÓN:
1. Asegúrese de tener instalado el SDK de .NET (.NET 9.0 o superior recomendado).
2. Abra Visual Studio o su entorno de desarrollo favorito.
3. Cree un proyecto de Aplicación de Consola en C#.
4. Reemplace el contenido del archivo Program.cs con el código fuente provisto.
5. Compile y ejecute la aplicación presionando el botón "Iniciar" o ejecutando "dotnet run" desde la terminal en la carpeta del proyecto.
